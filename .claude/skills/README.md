# Project skills

Copied from https://github.com/jeffallan/claude-skills (MIT, commit 882ef55), picked for this
stack (Spring Boot 3.5, Java 21, MongoDB, JWT). Reviewed before committing: they are plain
guidance and reference docs, with no scripts or instructions to fetch or run remote code.

- spring-boot-engineer, java-architect: Spring and Java patterns
- api-designer: REST conventions and error shapes (keep the live frontend's contract)
- security-reviewer, secure-code-guardian: auth, JWT, input validation, OWASP
- test-master, debugging-wizard, code-reviewer: tests, root-causing bugs, review passes
- database-optimizer: indexing and query tuning (examples are SQL; the ideas apply to MongoDB)

The security-reviewer penetration-testing notes are only for systems you own. Never run them
against third-party hosts.
